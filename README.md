# Sunbend releases

Official installers for [Sunbend](https://sunbend.app), a screen warmer and software dimmer.

Download and installation instructions: https://sunbend.app/download

Windows and Linux are beta releases. Supported display features vary by operating system and Linux desktop. See the release notes and download page before installing.

This repository contains distribution artifacts and release notes only. Sunbend is proprietary software, governed by https://sunbend.app/terms. Its source code is not included here.

Support: https://sunbend.app/contact
